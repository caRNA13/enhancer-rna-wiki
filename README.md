# Carlos students at EMBL wiki

**Enhancer RNA team**

A searchable handbook for Lab practice, Cell culture, and Genomic libraries, with a reagent-location directory and request forms. Students can read the website without accounts.

## Hosting

This repository contains the built static website. GitHub Pages serves the `main` branch from the repository root. No installation or build step is required for hosting.

## Updating the wiki

The editable project is maintained by Carlos. Edit its Markdown articles and location directory, run `python3 scripts/build.py`, and replace the corresponding website files here. The local project also includes a packaging script and a GitHub Actions workflow for deployments that keep the full source tree in a repository.

## Email requests

Reagent and wiki requests use FormSubmit. The recipient must activate the address and confirm inbox delivery before relying on notifications. The website itself is independent of the email service.
